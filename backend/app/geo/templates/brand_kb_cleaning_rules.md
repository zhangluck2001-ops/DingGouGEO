# 品牌资料清洗标准模板（母婴/跨境品类）

> 用法：每个品牌建一个文件夹，按本模板拆分文件。所有文件用 Markdown 保存。
> 清洗四原则：①原子化（一条事实一条记录）②带溯源 ③区分事实/宣称/话术 ④合规标注

---

## 清洗工作流（建议）

1. 原始PDF/Excel原封不动存入 `/原始资料/`，永不修改（溯源用）
2. 按模板逐份提取 → 每条信息标 ✅事实 / ⚠️宣称 / ❌话术 + 来源
3. 数字类信息（成分、价格、规格）必须与标签/凭证核对后才标✅
4. 每次品牌方更新资料，改对应Markdown并更新版本日期，不要另存副本
5. 用的时候：生成GEO内容 → 喂 02+04+06；做品牌诊断 → 喂 00+01+05；建官网 → 喂全部
```

## 证据等级（每条事实都要标）

| 等级 | 来源类型 | 能否写进对外内容 |
|---|---|---|
| A | 监管文件、国家标准、临床指南 | 可以，作为最强依据 |
| B | 产品标签、注册证、检测报告、资质证书 | 可以 |
| C | 品牌方声明（手册、培训资料、官网宣传） | 只能写成「品牌方表示」 |
| D | 第三方研究、行业报告、媒体评测 | 注明出处后可引用 |
| E | 社交媒体、评论区、客服记录里的说法 | 只能当作用户问法线索，**不能升级为事实** |

## 关键原则

- **账本里没有的，不许写。** 未核实的数据一律标「待核实」，不进入对外内容。
- 品牌自己的物料也会出错：清洗时发现与标签/官方最新资料冲突的，记为「存疑」并写明冲突点，不当卖点使用。
- 每条事实清洗后同时写一行到本地数据库 `~/.eigent/geo/geo.db` 的 `geo_fact` 表（模块、产品、字段、内容、类型、证据等级、来源），工作台「品牌知识库 → 知识条目」里就能查看和核对。
