# SMA 从零实测记录

用一个全新的空间，按真实用户的路径把 GEO 链路从头走一遍，每一步都记下预期、实际和问题，坏在哪里修哪里。

- 开始日期：2026-10-10
- 代码版本：`50a12bf4`（开始时）
- 实测空间：**SMA敏护实测**（项目 3，`space_9fa0471871c44c4f934a86bcf6298c56`，文件夹 `~/eigent/user_1/…`，注意不是 `~/.eigent`）。对照空间是「雀巢SMA敏护」（项目 2，旧，已预先导入过，不动）
- 模型：Codex 订阅 gpt-6.1-sol（要开着 Shadowrocket）
- 分工：用户在应用里操作；AI 在后台拍快照、看日志、填这份记录

> 记录里只写过程和现象，客户数据留在空间和快照里，不贴进仓库。

## 怎么观察

每一步**操作前、操作后**各拍一张快照，然后对比：

```bash
cd /Library/GEO/Eigent
python3 scripts/geo_observe.py spaces            # 看有哪些项目、新空间的 id
python3 scripts/geo_observe.py snap "上传资料前"
python3 scripts/geo_observe.py snap "上传资料后"
python3 scripts/geo_observe.py diff              # 最近两张：文件、表行、智能体运行
python3 scripts/geo_observe.py diff 0 1          # 空白 → 第 1 张（看新建时自动生成了什么）
```

- 默认看最新建的项目；看别的加 `--project ID`（放在子命令前面）。
- 快照存在 `~/.eigent/geo/observe/project_<id>/`，不进仓库。
- diff 里「智能体运行」一节来自 `~/.eigent/run-journal.sqlite3`：每次运行的状态、调用了哪些工具、模型调用次数、tokens 和报错。

上传用的资料已复制到 `/Library/GEO/实测资料/SMA原始资料/`（5 份，和旧空间原始资料一致）。**实际用户上传的是 3 份品牌方原件**：配料表及营养成分表 PDF、SMA品牌介绍.xlsx（11MB，内嵌图片）、雀巢SMA产品信息介绍.xlsx，更接近真实场景。

## 步骤

### 步骤 1 · 新建空间

**操作**：左侧栏「新建空间」，名称填 `SMA敏护实测`，然后打开它。

> 名字别和旧空间一样。旧空间的项目叫「雀巢SMA敏护」，同名会被自动改成「雀巢SMA敏护 (space_)」。

**预期**（`backend/app/geo/space_bootstrap.py`、`knowledge.py`）：打开空间时前端调 `POST /geo/spaces/ensure`，自动完成：

- 总表 `~/.eigent/geo/geo.db` 的 `geo_project` 多一行，带 `space_id` 和 `workspace_root`
- 空间文件夹 `~/.eigent/user_1/space_<id>/GEO/` 下生成：
  - `README.md`、`geo.db`
  - `01_品牌知识库/`：`原始资料/`（空）、`清洗规则.md`、`00_总览.md`…`06_合规红线.md`（模板，首行有模板标记）、`02_产品库/_SKU模板.md`
  - `02_意图探针/` … `08_效果追踪/` 七个空文件夹
- 空间若有 Git：`.git/info/exclude` 加上 SQLite 运行文件规则
- **不会**自动生成：原始资料、探针、采集轮次、`stage_skills.json`（品牌专属技能配置）

**实际**（快照 #1，10-10 11:15，此时已跑完清洗，骨架部分按文件核对）：骨架齐全；项目 3 名称已跟随改名为「SMA敏护实测」。

**问题**：
- 「从空白开始」不弹命名框，先建成「未命名空间」再改名。骨架在改名前生成，`README.md` 标题和七个模块模板里的品牌名都是「未命名空间」，改名后不会更新。→ 问题 1

### 步骤 2 · 上传原始资料

**操作**：知识库 →「资料与模块」→「上传资料」，选 `/Library/GEO/实测资料/SMA原始资料/` 里的 5 份。

**预期**：`原始资料/` 多 5 个文件，原件不动；`geo_kb_source` 多 5 行，状态「待清洗」。

**实际**：用户上传 3 份品牌方原件，`原始资料/` 3 个文件、`geo_kb_source` 3 行。没在上传前后单独拍快照。

**问题**：无

### 步骤 3 · 交给 AI 清洗（第 1 环）

**操作**：点「交给 AI 清洗 5 份」，只在智能体提问时回答，其余不插手。

**预期**（`docs/GEO-链路契约.md` 第 1 环完成标准）：

- 原始资料全部「已清洗」
- 七个模块都不是模板
- 命名表有标准名、首提全称
- `geo_fact` 每条有证据等级和来源；数字和功效类事实 100% 带 DOI 或官方 URL
- 合规红线模块不为空
- 总览「链路进度」第 1 环显示达标

**实际**（run `1791600973148-3825`，10:56:13 → 11:13:40，约 17.5 分钟，**失败**，界面显示「此任务无法继续」）：

| 10:57:20–10:59:49 | 编排者用 `ask_human_via_gui` 问「是否同意…」，纯文本框，无选项；用户答「确认」。**等了 2.5 分钟** |

产出质量（未验收）：
