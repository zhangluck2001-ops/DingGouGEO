## 一、全局约定

### 1.1 空间、轮次、批次

- **空间 = 一个品牌（或产品）**。链路的数据都在空间的 `GEO/geo.db`，文件放在 `GEO/01`–`08` 各环节文件夹。
- **轮次**：一次完整的 AI 采集。第一轮是优化前的基线，之后每次优化后复测一轮。
- **批次**：一组一起生产、一起发布的内容。

**一个优化周期**＝ 第 N 轮采集 → 诊断 → 引用来源分析 → 第 N 批内容 → 发布 → 第 N+1 轮复测。

现在数据里，内容既不知道自己依据哪一轮写的，也不知道是为哪个缺口写的，所以追踪回答不了「这批稿有没有用」。契约要求：**每批内容挂到它依据的轮次和缺口，每次复测挂到它要验证的批次。**

### 1.2 三份共用资产

| 资产 | 谁产出 | 谁用 |
|---|---|---|
| 品牌知识库：事实、命名、证据、红线 | 第 1 环 | 第 2、4、6 环 |
| 探针库 | 第 2 环 | 第 3 环（每轮从中选一个探针集） |
| 对标库：高被引原文及其结构 | 第 5 环 | 第 6 环 |

**品牌的事实和规则只放在知识库里，不写进技能。** 技能只写方法（怎么清洗、怎么诊断、怎么写），用到品牌信息时去读知识库。这样一套技能可以用在任何一个品牌空间。

### 1.3 指标口径

第 4 环和第 8 环用同一套指标，口径只在后端定义一处，页面、智能体、报告都调用它。

| 指标 | 定义 | 分母 |
|---|---|---|
| 提及率 | 回答中**真实提及**本品的比例。真实提及＝命中知识库「命名表」里本品的任一名称，且不是撞名。例：「托菲儿敏护」「金领冠敏护」不算 SMA | 有效回答 |
| TOP3 率 | 本品出现在回答推荐列表前三位的比例 | 有效回答 |
| 首提率 | 回答里第一个出现的品牌是本品的比例 | 有效回答 |
| 证据锚同段率 | 本品和知识库标记为「证据锚」的事实出现在同一段的比例。例：SMA 与 GINI、Bosheva 同段 | 提及本品的回答 |
| 顾虑率 | 回答里出现知识库标记的「扣分项」的比例。例：跨境、不含益生菌 | 提及本品的回答 |
| 事实吸收率 | 回答复述了知识库标记的「核心事实」的比例。例：每克 0.286 元、HMO 含量、召回已完成 | 提及本品的回答 |
| 目标内容被引 | 本空间已发布内容的链接出现在引用来源里的次数，以及涉及的回答数。链接先规范化（去参数、统一域名写法）再匹配 | — |

统计纪律：

- 有效回答＝本轮探针集里的**核心探针**在该平台的非空回答。另表题（品牌指向题、知识题、边界题）不计入。
- 每个率都**按平台分列**，同时报「回答条数」和「独立探针数」。同一探针在多个平台、多个轮次重复测量，属于伪重复，跨平台合并的数只作方向参考。
- 两轮对比**只比两轮都测过的探针**（取交集）。
- 提及、首提、TOP3 的自动判定，每轮人工抽检 10%，抽检记录随诊断结论保存。

SMA 的基线（第二轮，四平台 1,397 条）：提及率 4.8%，首提率 1.6%，顾虑率中「跨境」49/63。

## 二、八环契约

每一环写七项：目的、输入、产出、入口、做法与技能槽、完成标准、交接。完成标准尽量写成能机检的条件。

### 第 1 环 品牌知识库

| 项 | 契约 |
|---|---|
| 目的 | 一份可核验的品牌事实底座。后面每一环只认它，知识库里没有的不写 |
| 输入 | `01_品牌知识库/原始资料/`：品牌方资料、官网页面、标签照片、检测报告、文献表、客服问答。原件永远不改 |
| 产出 | ① 七个模块文件 `00_总览`…`06_合规红线`，产品逐个写 `02_产品库/<产品名>.md`；② 表 `geo_fact`，每条有模块、产品、字段、内容、类型（事实／宣称／话术；资料互相矛盾标存疑，完全没有出处标待核实）、证据等级 A–E、来源（原件文件名 + 位置，资料里有 DOI 或官方 URL 一并写上）；③ **命名表**：标准名、首提全称、沿革句、别名、撞名排除词；④ **事实角色**：核心事实、证据锚、扣分项（供第 4 环算指标，第 6 环写稿） |
| 入口 | 知识库页「资料与模块」：上传资料（上传时程序自动解析到 `原始资料解析/<文件名>/`：`内容.md` 带位置的文字、`图片/` 需要看的图、`清单.json`；PDF 扫描页转成图片，Excel 单元格图片和嵌入附件一并拆出）→「交给 AI 清洗」 |
| 做法与技能槽 | 规则：`清洗规则.md`（已随空间生成）。技能：**暂无**，用《品牌资料清洗标准模板》和 SMA 统一知识库的做法写成清洗技能。读资料不用 pdf、docx、xlsx 技能，也不让智能体自己写程序解析：读 `内容.md`，只对清单里的图用 `read_image` |
| 完成标准 | 原始资料全部「已清洗」；七个模块都不是模板；命名表有标准名、首提全称；每条事实有证据等级和来源（原件文件名 + 位置）；功效、临床类宣称带 DOI 或官方 URL，没有的标明缺口；合规红线模块不为空 |
| 交接 | 品类、CEP、卖点、竞品 → 第 2 环；命名表、事实角色 → 第 4 环；事实、证据、红线、命名 → 第 6 环 |
| SMA 现状 | 应用里 0 条。桌面《SMA敏护品牌统一知识库.md》已按模板清洗完（109KB），09-28 方案 §3–4 有核实过的证据库和标准事实包，召回事实另有底表。**导入即可，不用重做** |

| 产出 | 表 `geo_probe`：编码、问题文本、CEP、框架、品牌指向、卖点、NO_GO、审校状态（现有值：核心探针、暂停使用；另表题要单独标出）、真实咨询依据；探针分组（一个账号测一组，库里现为「轮换-表1」到「轮换-表5」） |
| 入口 | 探针页「交给 AI」：按你给的方向起草 → 你确认后才入库 |
| 做法与技能槽 | 口径（SMA v3）：只收非品牌、求推荐型；不用「选哪款」这类只给一个答案的问法；不写排除本品的条件，也不硬塞本品卖点；知识题、品牌指向题、边界题放另表，不计入提及率；当前 0 提及的真实问题要保留，那是内容缺口。技能：**暂无**，把这套口径写成探针设计技能 |

| 交接 | 本轮探针集（核心探针＋分组）→ 第 3 环 |
| SMA 现状 | 应用里 394 条（从飞书导入）：核心探针 300 条，暂停使用 94 条；300 条核心探针都已分到轮换表 1–5（70／64／64／55／47 条）。另表题和真实咨询依据还在 v3 xlsx 里 |

| 运维约束 | 登录 profile 不得清除或改名；每个账号有单会话上限，撞上验证或风控立即停批，交给人处理；不得强杀浏览器（会丢登录） |

| SMA 现状 | 两轮数据已导入（回答 4,954 条、来源 82,699 条）。采集脚本在应用外跑，写的是飞书 |
